## User story

As an advanced user, I want future layout options to address real limitations of the initial grid canvas.

## Scope and implementation notes

- Collect feedback on free pixel positioning, overlap/layers, nested sections, reusable compositions, named layouts, and slideshows.
- Evaluate geometry, keyboard access, desktop window adaptation, performance, storage migration, and export consequences.
- Keep layout exploration desktop-only; mobile/tablet layouts and separate narrow-layout editing are out of scope.
- Keep cloud sync, marketplaces, remote executable widgets, and arbitrary CSS outside the current commitment.

## Acceptance criteria

- [ ] Each candidate has a concrete user problem and an explicit adopt/defer decision.
- [ ] Any selected feature receives a separate story and migration/accessibility design before implementation.
- [ ] The current grid model and intentional spaces remain stable while experiments are evaluated.

## Verification

Roadmap only for 2.0.0. Do not change the core storage model speculatively for unapproved advanced features.
